# VYRA source restoration package

This archive was reconstructed from the VYRA source archive previously uploaded in ChatGPT and the evaluation enhancement files prepared during the evaluation work.

Included: Django/DRF backend source, RAG pipeline, retrieval, knowledge ingestion/services, LLM integration, tests, requirements manifests, and evaluation framework.

Intentionally excluded: Gmail OAuth client/token credentials, logs, local database/vector-store data, virtual environments, compiled Python files, and knowledge-base PDFs. Re-add your own approved knowledge-base documents locally.

## Restore
Extract this archive into your home directory. It creates a `Vyraa/` folder. Then create/activate a virtual environment and install dependencies from `requirements.txt`.

Do not commit API keys, OAuth credentials, private user data, logs, or copyrighted source PDFs to a public repository.
